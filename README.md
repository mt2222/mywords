# 단어톡 0.2 — 시험지 기반 단어 학습 PWA

## 이번 버전에 들어간 기능
- iPhone 카메라/사진 앨범에서 시험지 사진 선택
- Tesseract.js 영어+한국어 OCR (인쇄 글자 중심; 손글씨 인식은 불안정)
- OCR 원문을 확인하고 `영어 단어 | 아이 답안 | 정답 뜻` 형식으로 편집
- 내장 유사어/표현 비교를 통한 보수적 의미 채점
- 애매한 답은 오답 처리하지 않고 `확인 필요`로 분류
- 부모가 각 항목을 정답/오답/확인 필요로 최종 확정
- 영어→한글 / 한글→영어 카드 학습, 스와이프, 알고 있음/다시 보기
- 오답 및 확인 필요 항목만 학습
- 브라우저 localStorage 저장, TXT 내보내기
- PWA 홈 화면 설치 지원

## AI 채점 관련 중요한 설명
이 버전은 **실제 생성형 AI가 기본 탑재된 앱은 아닙니다.** 브라우저에 AI 서비스의 비밀 API 키를 넣으면 키가 노출될 수 있으므로, 실제 AI 의미 채점은 별도 HTTPS 서버를 통해 연결하도록 설계했습니다. 서버 URL을 설정하지 않으면 내장된 제한적 유사어/반대말 규칙으로 채점하고, 확신이 없으면 `확인 필요`로 둡니다.

서버 연동 계약:
- 요청: `POST /grade`, JSON `{ "items": [{ "en": "accurate", "studentAnswer": "부정확한", "correctMeaning": "정확한" }] }`
- 응답: JSON `{ "results": [{ "index": 0, "verdict": "wrong", "reason": "정답 의미와 반대되는 표현입니다." }] }`
- verdict는 `correct`, `wrong`, `uncertain` 중 하나
- API 키는 브라우저가 아니라 서버 환경변수에 보관해야 합니다.

## 시험지 사용 흐름
1. 시험지 사진을 찍고 `사진에서 글자 읽기`를 누릅니다.
2. OCR은 원문 텍스트를 추출합니다. 시험지 표의 행/열 및 아이 손글씨는 잘못 읽힐 수 있습니다.
3. `영어 | 아이 답안 | 정답 뜻` 형식으로 편집하거나 정리합니다.
4. `단어 행 만들기` 후 세 칸을 검토합니다. 손글씨 답안이 잘못 읽힌 경우 직접 수정합니다.
5. `의미 기준으로 채점하기`를 누릅니다.
6. `채점 확인` 화면에서 결과를 검토하고 필요하면 정답/오답을 직접 변경한 뒤 저장합니다.
7. 카드 학습에서 영어→한글 또는 한글→영어를 선택합니다.

## Windows에서 실행
- 압축을 풀고 폴더에서 터미널을 엽니다.
- Python이 설치되어 있다면 `python -m http.server 8000` 실행
- 브라우저에서 `http://localhost:8000` 접속
- Python이 없다면 Visual Studio에서 파일을 편집할 수 있지만, 브라우저의 카메라/PWA 기능 테스트에는 로컬 HTTP 서버가 편리합니다.

## iPhone에 설치
1. GitHub에 새 저장소를 만들고 `index.html`, `manifest.webmanifest`, `sw.js`를 올립니다.
2. Settings → Pages에서 배포하고 HTTPS 주소를 받습니다.
3. iPhone Safari로 접속 → 공유 → 홈 화면에 추가
4. 최초 OCR 시 인터넷 연결이 필요합니다.

## 현재 한계 / 다음 개선점
- 손글씨 한글 OCR은 정확도가 낮습니다. 현재는 OCR 결과를 부모가 직접 확인·수정하는 흐름입니다.
- 실제 AI 채점 서버는 별도 구축이 필요합니다. API 키를 정적 웹앱에 넣지 마세요.
- 데이터는 기기/브라우저별로 따로 저장되며 자동 동기화되지 않습니다.
- 내장 유사어 목록은 제한적이므로 새로운 표현은 `확인 필요`로 갈 수 있습니다. 부모 검토가 의도된 안전장치입니다.
