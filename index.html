이번 버전의 채점 방식

정답 문장과 아이 답안이 글자 그대로 같지 않아도, 등록된 유사어·뜻 표현을 비교합니다. 판단이 불확실한 답은 오답으로 단정하지 않고 부모 확인 목록에 둡니다.

중요: 현재 앱은 브라우저에서 동작하는 MVP입니다. 실제 생성형 AI 채점은 보안상 API 키를 앱에 넣지 않고 별도 서버를 연결해야 합니다. 서버를 연결하지 않은 상태에서는 내장된 뜻/유사어 규칙으로 보수적으로 채점합니다.

시험지 사진 등록

사진에서 영어 단어와 인식 가능한 글자를 추출합니다. 손글씨 한글은 OCR 오류가 잦으므로 답안 칸에서 꼭 확인·수정해 주세요.

OCR 원문 / 직접 붙여넣기

OCR 결과가 표 형태로 정리되지 않을 수 있습니다. 아래 입력란을 확인한 뒤 [단어 행 만들기]를 누르세요. 형식: 영어단어 | 아이가 쓴 뜻 | 정답 뜻

단어 / 아이 답안 / 정답 뜻 확인

사진에서 손글씨가 잘 읽히지 않으면 아이가 쓴 답을 직접 입력해 주세요. 정답 뜻도 확인할 수 있습니다.

채점 결과 확인

의미가 비슷하면 정답으로 처리하고, 뜻이 반대이거나 분명히 다르면 오답으로 표시합니다. 애매한 경우 부모가 최종 결정해 주세요.

AI 채점 서버 연결 (선택)

실제 AI 의미 채점을 사용하려면 본인 서버의 HTTPS 주소를 입력하세요. 브라우저에 OpenAI 등의 비밀 API 키를 직접 입력하거나 저장하지 않습니다.

서버는 POST JSON {"items":[{"en":"...","studentAnswer":"...","correctMeaning":"..."}]} 를 받고, {"results":[{"index":0,"verdict":"correct|wrong|uncertain","reason":"..."}]} 형태로 응답해야 합니다. 미설정 시 내장 규칙으로 채점합니다.
